## Fixed this session (real bug found by running, not in the old notes)

**API container crash-looped: `Router.__init__() got an unexpected keyword
argument 'on_startup'`.** The image had `starlette 1.3.1` installed next to
`fastapi 0.115.6` (which requires `starlette<0.42`). Root cause: the
`pip install semgrep` layer runs **after** the requirements.txt layer and
silently upgrades starlette (semgrep's transitive web-stack deps require
`starlette>=0.49.1`). The worker survived only because it never imports the
FastAPI routes. Fix: semgrep is now installed into its own venv
(`/opt/semgrep-venv`, symlinked onto PATH) so the two dependency trees can no
longer clash. The requirements.txt `starlette==0.41.3` pin was already in
place (matching the host venv) and is now effective in the image.

## Earlier fixes (from the first M1 session, kept for reference)

1. **Enrichment path bug (found by first e2e run):** `semgrep.py`/`gitleaks.py`
   ran tools with `cwd=target` while passing relative paths — resolved
   `target`/`report_path` to absolute before invoking tools.
2. **`test_mastg.py` pytest collection error:** alias `test_ids_for_control`
   renamed to `reverse_lookup`.
3. **Ruff violations:** 2× E501 + 1× F401 in `manifest.py`, 1× I001 in
   `test_mastg.py` — all clean.
4. **Signing-certificate bug (found by integration test):** `_certificate_findings`
   used cryptography-style `not_valid_before_utc` on androguard's asn1crypto
   `Certificate`; now uses `not_valid_before`/`not_valid_after`/`sha256.hex()`.
5. **Semgrep scope tagging off-by-one:** relative the path before the package
   check (tolerant of both `root=<sources>` and `root=<decompiled>`).

## Decisions that weren't in the original plan

1. **MASTG mapping source of truth is per-test YAML front matter**, not an
   aggregate JSON — upstream publishes none. The sync script parses the
   tarball's `tests/` + `tests-beta/` front matter and builds the lookup.
2. **Vendored mapping lives in `app/analysis/resources/`, not `data/`** —
   `.gitignore` ignores any directory named `data/`.
3. **Sync pins the recorded ref to a resolved commit SHA** (via the GitHub API)
   rather than a branch name, so the vendored data is reproducible.
4. **Semgrep rules: use MASTG's own `rules/mastg-android-*.yml`** (46 rules,
   `[MASVS-*]` ids already in messages) instead of hand-writing the full
   OWASP-style set; a small curated `rules/masa/` set supplements it.
5. **`semgrep` pip package pinned at 1.172.0**, always run with
   `--oss-only --metrics off`; installed in an isolated venv (see above).
6. **Gitleaks pinned at 8.30.1** (host parity).
7. **Manifest check categories corrected against real vendored data:**
   `debuggable` → `MASVS-RESILIENCE-4`; `allowBackup` → `MASVS-STORAGE-2`.
   `mastg_test_id` is backfilled from the mapping's control→test reverse lookup.
8. **Scope (owner decision):** engine + RQ job + CLI only — no upload/findings
   API in M1.
9. **Secrets severity (owner decision):** gitleaks defaults to `high`, with a
   per-rule override table (e.g. `aws-access-token`, `private-key` → `critical`).
10. **Semgrep third-party tagging (owner decision):** findings are kept but
    tagged `detail.scope: app | third_party_library` (plus
    `detail.in_app_package`) so the dashboard can filter/group library noise.

## How to run (verified working)

```bash
# Host (no Docker): synchronous analysis
cd backend && .venv/bin/python -m app.cli run ../docs/InsecureBankv2.apk --out /tmp/m1.json

# Compose stack: API + RQ worker + Redis
docker compose up -d --build
curl localhost:8000/api/v1/health        # → {"status":"ok","redis_ok":true,"db_ok":true}

# Enqueue a scan through the compose worker (needs the APK inside a container)
docker cp docs/InsecureBankv2.apk masa-app-1:/tmp/InsecureBankv2.apk
docker compose exec app python -m app.cli scan /tmp/InsecureBankv2.apk

# Tests
cd backend && .venv/bin/python -m pytest                       # 27 unit tests
cd backend && .venv/bin/python -m pytest -m integration        # 6 integration tests
# (the RQ round-trip test needs a worker on MASA_REDIS_URL, e.g. `python worker.py`)
```
